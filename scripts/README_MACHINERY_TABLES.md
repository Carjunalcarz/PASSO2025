# Machinery Tables Setup Script

## Overview
This script creates the machinery-related database collections in Appwrite based on the schema design.

## Tables Created

### 1. machinery_types
**Purpose**: Stores different types of machinery

**Attributes**:
- `machinery_type_id` (PK) - Auto-generated by Appwrite as `$id`
- `name` (string, 500, required) - Name of the machinery type
- `description` (string, 500) - Description of the machinery type
- `status` (string, 50) - Status (active/inactive)

**Indexes**:
- `name_index` - Index on name field
- `status_index` - Index on status field

### 2. machinery_rates
**Purpose**: Stores rate information for each machinery type

**Attributes**:
- Auto-generated `$id` (PK)
- `name` (string, 500) - Name/description of the rate
- `rate` (float) - The rate value (percentage)
- `effectivity_date` (datetime) - Date when the rate becomes effective
- `status` (string, 50) - Status (active/inactive)
- `machinery_type_id` (string, 50, FK) - Foreign key to machinery_types

**Indexes**:
- `machinery_type_fk_index` - Index on machinery_type_id (FK)
- `status_index` - Index on status field
- `effectivity_date_index` - Index on effectivity_date field

## Relationship
```
machinery_types (1) ──→ (N) machinery_rates
```

## Usage

### Prerequisites
1. Ensure you have Node.js 18+ installed
2. Make sure your `.env` file contains:
   - `VITE_APPWRITE_ENDPOINT`
   - `VITE_APPWRITE_PROJECT_ID`
   - `VITE_APPWRITE_DATABASE_ID`
   - `APPWRITE_API_KEY` (with Database permissions)

### Running the Script

```bash
npm run setup:machinery
```

Or directly:
```bash
node scripts/setup-machinery-rates.js
```

### What the Script Does
1. Deletes existing `machinery_types` and `machinery_rates` collections (if they exist)
2. Creates new collections with proper permissions
3. Creates all required attributes with correct data types
4. Creates indexes for optimized queries
5. Provides a summary of created tables

### After Running
Add these environment variables to your `.env` file:
```env
VITE_APPWRITE_MACHINERY_TYPES_COLLECTION_ID=machinery_types
VITE_APPWRITE_MACHINERY_RATES_COLLECTION_ID=machinery_rates
```

## Troubleshooting

### API Key Issues
If you get authentication errors:
1. Go to Appwrite Console → Overview → API Keys
2. Create a new API key with "Database" scope
3. Add it to `.env` as `APPWRITE_API_KEY`

### Connection Issues
If you can't connect to Appwrite:
1. Verify `VITE_APPWRITE_ENDPOINT` is correct
2. Ensure Appwrite server is running
3. Check network connectivity

### Collection Already Exists
The script automatically deletes existing collections before creating new ones. If you want to preserve data, backup first.
